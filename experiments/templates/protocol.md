# Protocol template

複製到新實驗目錄後填寫；這是範本，不是已完成的 protocol。

- Experiment ID / 作者 / 日期 / 狀態：
- Learn：哪些一手來源支持問題？哪些是不確定的類比？
- Hypothesis：能被否證的單一句子。
- Baseline / treatment：改變什麼、固定什麼、因果辨識限制。
- Metrics：分母、單位、觀察區間、未完成與缺失資料的處理。
- Success threshold：執行前固定的工程門檻與不確定性要求。
- Workload / data：來源、版本、授權範圍、train/test split 或 seeds。
- Build：依賴、命令、運算需求、不可搶占／失敗模型等假設。
- Measure：重複次數、配對設計、CI、預定敏感度與停止條件。
- Critique：可能失敗的原因、公平性、模型界線、外推風險。
- Improve：哪些變更須新 protocol，哪些資料保留作獨立驗證。
