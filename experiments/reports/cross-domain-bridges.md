# 跨領域連結：可測試的轉譯，不是既定結論

## 排程 → 機器人 → 施工

共同結構是受限的執行者、共享資源、工作與時間。然而 CPU 可以快速搶占，機器人走廊與施工吊裝不一定能安全中斷；施工還有工序前置、班次、材料與天候。RRL-001 的結果只支持其 reservation 模型。

可測的下一步：先用 SYS-001 分離 matching / aging / SPT 的效果，再在 CON-002 新增 precedence 與班次，重新固定成功門檻。

## AI 文件擷取 → 土木與法律資料

共同需要來源位置與版本。AI-001 評估抽取是否可驗證；CON-001 提供文件欄位與人工標註。抽到某條款的文字不代表已確定法律效力；法律資料另需日期、管轄與適用範圍。

可測的下一步：對同一測試文件，比較 regex、OCR pipeline 與有證據定位的模型輸出，記錄 precision、recall、錯誤來源與人工核驗時間。尚未取得此類資料或執行此測試。

## 材料與工法 → 商業模式與現金流

較低材料單價可能伴隨較長工期、設備需求或失敗機率。XDS-001 應把物理性能、施工限制、成本與付款時點連在一個明確決策情境中，再做敏感度分析。

目前沒有金融或法律結論；以上都是下一個 protocol 的研究方向。原始量測來源：[RRL-001 findings](../../robotics/resource-scheduling/docs/findings.md)。

## SYS-001 更新

機制拆解已完成，三個主要假說未在兩批同時達門檻；aging 的尾端等待收益伴隨平均等待與 deadline 代價。[新證據](../../computer-systems/process-scheduling/findings.md) 不構成施工或 CPU 排程的外部驗證。
